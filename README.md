# 🏓 Ping Simulator AFTT

> Calculateur de points AFTT — Outil non officiel par **PurpleNicode**

---

## 📱 Accéder à l'application

👉 **[purplenicode.github.io/aftt_ping](https://purplenicode.github.io/aftt_ping/)**

Fonctionne sur smartphone Android et iPhone, directement dans le navigateur — sans installation depuis un store.

---

## 📲 Installer l'app sur ton téléphone

Pour l'avoir comme une vraie application avec une icône sur l'écran d'accueil :

**Sur Android (Chrome) :**
1. Ouvre le lien dans Chrome
2. Appuie sur le menu ⋮ (trois points)
3. "Ajouter à l'écran d'accueil"

**Sur iPhone (Safari) :**
1. Ouvre le lien dans Safari
2. Appuie sur le bouton Partager ⬆️
3. "Sur l'écran d'accueil"

---

## ✨ Fonctionnalités

- 📊 Calcul d'évolution des points selon le barème officiel AFTT
- 👥 Gestion de plusieurs profils joueurs
- 🏆 Interclubs Messieurs, Interclubs Dames et Tournois
- ♀️ Double compteur points Messieurs / Dames pour les joueuses
- 📅 Suivi mensuel avec clôture de mois
- 💾 Données sauvegardées localement sur ton téléphone

---

## ⚠️ Avertissement

Cet outil est **non officiel** et **non affilié à l'AFTT**.  
Les calculs sont fournis à titre indicatif et peuvent différer des résultats officiels.  
Consultez toujours [data.aftt.be](https://data.aftt.be) pour vos points officiels.

## 🛠️ Technologie

Application web progressive (PWA) — un seul fichier HTML, aucun serveur, aucune donnée envoyée en ligne.  
Hébergé gratuitement sur GitHub Pages.
